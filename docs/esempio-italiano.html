Esempio JSGantt in Italiano

Questo è un esempio di JSGantt Chart con l'interfaccia in italiano.

Spiegazione dei Parametri

I parametri principali utilizzati in questo esempio sono:

  • vLang: 'it' - Imposta la lingua dell'interfaccia in italiano
  • vCaptionType - Controlla quale campo visualizzare come didascalia sulla barra delle attività
  • vDateTaskDisplayFormat - Formato della data visualizzato nei tooltip
  • vShowTaskInfoLink - Mostra/nascondi il link "Più Informazioni" nel tooltip
  • vUseSingleCell - Soglia per l'ottimizzazione delle prestazioni su grafici grandi
  • vFormatArr - Formati di visualizzazione disponibili (Giorno, Settimana, Mese, Trimestre)

Parametri delle Attività (Task)

  • pID - ID univoco dell'attività
  • pName - Nome dell'attività
  • pStart/pEnd - Date di inizio e fine
  • pRes - Risorsa assegnata
  • pComp - Percentuale di completamento (0-100)
  • pGroup - Indica se è un gruppo (1) o attività normale (0)
  • pParent - ID dell'attività padre
  • pDepend - Dipendenze da altre attività
  • pCost - Costo dell'attività
  • pMile - Indica se è una milestone (1) o meno (0)
